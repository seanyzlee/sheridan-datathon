# Resilience Rewired · Frontend

React + Vite + TypeScript Advisor Console for the Tangerine track.

```bash
npm install
npm run dev        # http://localhost:5173 (mock data, no backend needed)
npm run build      # strict type-check + production build
```

To use the FastAPI engine, put `VITE_DATA_SOURCE=live` in `.env.local` (see `.env.example`).

Full guide, the API contract and the demo script: [`../docs/frontend_implementation.md`](../docs/frontend_implementation.md).
